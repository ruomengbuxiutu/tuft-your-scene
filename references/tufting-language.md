# 可识别插画型 Tufting 视觉语言

这份规则来自用户提供的花卉、角色、动物、像素拼图和卡通地毯参考。只提炼共同视觉规律，不复制任何具体角色或作品。

## 1. 中等提炼区间

目标不是完整写实场景，也不是无语义几何抽象。

| 指标 | 建议区间 |
|---|---:|
| 主体面积 | 55%–80% |
| 主要形状 | 8–18 个 |
| 身份特征 | 3–8 个 |
| 主要颜色 | 5–9 色 |
| 背景大区块 | 1–3 个 |
| 高绒重点 | 2–6 处 |
| 鲜艳色面积 | 10%–30% |

形状数按“能独立识别的大色块”计算。花卉可以有多片花瓣，角色可以有脸部与肢体，桥梁可以有 3–5 个拱洞；但密集重复纹理必须合并。

## 2. 主体识别

### 角色与动物

- 外轮廓与姿态优先；
- 五官数量少但位置准确；
- 保留耳朵、尾巴、面部花纹、服饰主形；
- 身体略短宽、脸或爪略放大，可提高可爱度；
- 深色轮廓可明显，但线宽稳定。

### 花卉与植物

- 花朵保持 4–7 瓣的可识别花型；
- 叶片保留中脉方向，但省略细叶脉；
- 允许 5–12 个花/叶单元形成节奏；
- 高绒集中在花瓣、花心或叶片中部。

### 车辆与建筑

- 用 3–8 个结构特征保留身份；
- 车头、车身方向、桥拱、屋顶或招牌外形可以保留；
- 窗户、砖纹和机械零件只选少数代表性元素；
- 背景建筑群合并为 1–3 个天际线块。

### 风景

- 保留 2–4 组前中后景；
- 树林可简化为 3–7 个树冠/树形，不必只剩一块云；
- 水体、道路、雾带或山脊要保持方向和位置；
- 允许明显景物，但拒绝摄影级微细节。

## 3. 颜色平衡

参考图的共同点不是低饱和，而是“亮色被浅色和深色稳住”。

推荐结构：

- 浅色 20%–45%：奶油白、柔白、浅灰蓝、淡沙；
- 中等饱和色 35%–60%：青草绿、天空蓝、粉红、黄、橙、棕；
- 深色 8%–20%：黑、深蓝、可可棕、墨绿；
- 鲜艳重点色 10%–30%：亮粉、黄、宝蓝、珊瑚红、橙。

允许的清爽组合：

- 粉红 + 黄 + 宝蓝 + 奶油白 + 暖棕；
- 草绿 + 浅蓝 + 花粉 + 黄 + 奶油白 + 砖橙；
- 黑 + 奶油白 + 腮红粉 + 少量亮蓝；
- 橄榄绿 + 苔绿 + 粉紫 + 红 + 白 + 深棕。

避免两种极端：

- 所有颜色都混入大量灰，画面失去生命力；
- 所有颜色都用最高纯度，画面像塑料玩具或荧光海报。

## 4. 轮廓与立体

- 主体可用深色轮廓，宽度约为主体宽度的 1.5%–4%；
- 花卉可少用外轮廓，以高低绒和色差分界；
- 角色/动物使用清晰轮廓能提高识别度；
- 轮廓边缘略有手工弯曲，但不能毛躁散线；
- 高绒重点比背景高 3–10 mm，足以形成柔软投影；
- 压凹色块、雕刻沟槽与高绒共同产生 3D 感。

## 5. 外轮廓

- 角色、动物、花束、车辆优先沿主体剪影形成异形地毯；
- 风景或多主体可使用圆角矩形、椭圆或柔和不规则底垫；
- 外轮廓需要完整稳固，不能为保留小细节产生大量尖刺；
- 背景底垫应支持主体，不占据视觉中心。

## 6. 文字规则

默认零文字：

`no text, no letters, no numbers, no logo, no caption, no watermark, no signature`。

只有用户明确给出字符串时才允许加入；必须逐字使用、尺寸克制、属于地毯本体。参考图中的平台文案、标签、品牌、角色名称均不得进入成品。

## 7. 排除词

`gray cast, dusty desaturation, monochrome beige, extreme geometric abstraction, unrecognizable subject, photorealistic miniature, every window, every leaf vein, every mechanical part, neon overload, poster typography, added caption, Chinese characters, random English phrase, logo, watermark, knitted fabric, crochet, embroidery, needle felt, loose yarn`。
